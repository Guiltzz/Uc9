#UC9

📌 Sobre

Aqui reúno o que venho estudando e praticando: desenvolvimento de aplicações em Java integradas a um banco de dados relacional, com interface gráfica em Java Swing e conexão via JDBC com o PostgreSQL.

📚 O que estou aprendendo
Conexão entre Java e banco de dados com JDBC
Configuração do driver JDBC do PostgreSQL
Comandos SQL executados pelo Java: INSERT, SELECT, UPDATE e DELETE
Consultas seguras e parametrizadas com PreparedStatement
Interfaces gráficas com Java Swing
Exibição e manipulação de dados em tabelas com JTable e DefaultTableModel
Tratamento de exceções com try/catch/finally
Boas práticas, como o fechamento correto das conexões

🛠️ Tecnologias
Java: linguagem principal
Java Swing: interface gráfica
JDBC: conexão com o banco de dados
PostgreSQL: banco de dados
NetBeans: IDE de desenvolvimento


🎯 Objetivo

Evoluir na programação em Java, praticando a construção de sistemas completos, desde a interface até a persistência dos dados.
